## NVIDIA CUDA Toolkit and cuFFT

Janus Universe uses the CUDA Toolkit and cuFFT. The prebuilt
`Janus-Universe-win64-full.zip` archive includes `cufft64_12.dll` under the
redistribution terms of the NVIDIA CUDA Toolkit EULA (Attachment A). The EULA
is included in that archive as `licenses/NVIDIA-CUDA-EULA.txt`. The lean
archive does not redistribute NVIDIA files; it requires CUDA Toolkit 13.1 on
the target machine.

## 3Dconnexion SDK (optional)

A build configured with `JANUS_WITH_3DCONNEXION=ON` links the 3Dconnexion
NavLib SDK in object-code form under the 3Dconnexion SDK License Agreement.
That licence requires the following attribution in the application's About or
Help box, which the source displays in that build:

```
3D input device development tools and related technology are provided under
license from 3Dconnexion. (C) 3Dconnexion 1992 - 2025. All rights reserved.
```

The SDK itself is **not** part of this repository and is not redistributed as
source. A build with the default `JANUS_WITH_3DCONNEXION=OFF` contains no
3Dconnexion code.

## Microsoft Visual C++ runtime

The prebuilt archives may contain `MSVCP140.dll`, `VCRUNTIME140.dll` and
`VCRUNTIME140_1.dll`, which are Microsoft Visual C++ Redistributable files.
They are (C) Microsoft Corporation and are redistributed under the Microsoft
Visual Studio licence terms. They are provided to make the archives run on
machines that do not already have the Visual C++ 2015-2022 Redistributable

## Qt / OpenGL / Windows SDK

No Qt component is used. OpenGL and the Windows SDK are provided by the
operating system and the graphics driver.
